# Cyber Arsenal 🛡️

Cyber Arsenal is a collection of Python-based cybersecurity and penetration testing tools built with Python, focused on learning and ethical hacking.

## Included Tools
- Network scanners
- Web directory enumeration
- Subdomain discovery
- Hash identification & cracking

## Environment
- Python 3
- Kali Linux
- SecLists wordlists

## Disclaimer
This project is for educational purposes and authorized testing only.
